# Variant tables

> ### Not for clinical use
>
> These functional scores are research data from a study that has not yet completed peer
> review. **They must not be used for clinical diagnosis, variant interpretation, patient
> management, or any other clinical purpose.** Classification of a variant for clinical
> purposes requires the full evidence framework, of which an experimental functional assay
> is one component among several.

| file | contents |
|---|---|
| `supplementary_data_1.xlsx` | one row per variant (13,919) |
| `supplementary_data_2.xlsx` | one row per annotated oligo (17,533), so a variant reachable by more than one oligo appears more than once |

Both have the title in row 1, the column header in row 2, and a second sheet documenting
every column. Both are regenerated by `run_pipeline.R`; the copies here are committed so
they can be read without running anything.

See the repository README for how the scores are derived and what the columns mean.
