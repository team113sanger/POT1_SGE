## Why the two sets are not bit-identical

The two sets describe the same 13,919 variants and the same 17,533 oligos, with the same
119 columns and the same values in all but fifteen of them. Where they differ, they differ
by amounts far below anything the analysis resolves:

| | largest difference |
|---|---|
| `functional_score`, `LFC_continuous` | 1.5e-10 |
| `BH_FDR_continuous` | 9.4e-08 |
| `LFC_` and `SE_` on the four discrete contrasts | 4.8e-07 |
| `C1_z`, `C2_z`, `uncertainty` | 5.0e-07 |
| `two_tailed_p_` and `BH_FDR_` on the discrete contrasts | 3.7e-06 |
| `z_` on the discrete contrasts | 1.3e-05 |

**Every functional classification is identical, and no variant crosses an FDR threshold of
0.01 or 0.05 on any contrast.** Nothing the paper reports depends on the difference.

### Where it comes from

DESeq2 fits a parametric mean–dispersion trend where it can and falls back to a local
regression where it cannot. That choice is made by an iterative Gamma GLM started at a fixed
point, which stops with an error if a coefficient becomes non-positive on the way; DESeq2
then silently substitutes the local fit.

For one library whose asymptotic dispersion is close to zero, the default starting point
overshoots. Whether the parametric fit converges therefore turns on differences of around
1e-9 in the per-variant dispersion estimates — differences that arise from compiled code and
numerical libraries rather than from the data. The same DESeq2 version on different hardware
can take either branch.

`fit_dispersion_trend()` in `../R/03_deseq.R` removes that sensitivity: it tries the
parametric fit from DESeq2's own starting point and then from progressively smaller
asymptotic dispersions, falling back to a local regression only if none converge. The model
and DESeq2's convergence criterion are unchanged; only the starting value differs. The
consequence is that the pipeline makes the same choice of fit on any machine, and the
residual differences above are what remains — floating-point noise inside DESeq2's own
convergence tolerance.

See the repository README, *The dispersion trend*, for the full account.

### Row order

The two sets also list rows in a different order. Both group by mutator and then by
descending genomic position; they differ only in how rows sharing both are ordered. Nothing
depends on it. Compare the two on `mseq` and `id` rather than by row position.
